# EuRoC MAV acquisition status

Official source: https://ethz-asl.github.io/datasets/euroc-mav/

DOI: https://doi.org/10.3929/ethz-b-000690084

The complete official archive was not available locally at validation time. A zero-byte browser transfer temporary file is not a dataset and is excluded from metrics. `EurocImuAdapter` is ready for the official `mav0/imu0/data.csv` format. Before evaluation, record the selected sequence, license, byte size, SHA-256, calibration, timestamp synchronization, and ground-truth alignment.
