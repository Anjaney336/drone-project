# Problem statement

Can a monitoring platform maintain a bounded and inspectable state estimate, recognize degraded navigation evidence, and recommend a safe response when individual drone sensors or telemetry channels become unreliable?

AERIS targets protected infrastructure, industrial sites, disaster response, and managed airspace. It does not perform destructive interception, jamming, or weaponized control. Current evidence is limited to simulation and explicitly labelled synthetic supporting data; no public visual dataset currently contributes a reported result.
